# prompts

Gemini 에 보내는 프롬프트 본문. 한 파일이 한 섹션이고, 파일 이름이 그대로 섹션 이름이 된다(`-` 는 공백으로).

- `shared/` 는 두 개 이상의 프롬프트가 쓰는 섹션만. 한 프롬프트만 쓰면 그 프롬프트 폴더에 둔다.
- 자리 표시자는 `{{이름}}` 하나뿐이다. 반복·조건·필터는 없다 — 필요하면 Kotlin 에서 값을 만들어 넘긴다.
- **값이 없는 자리와 쓰이지 않은 값 둘 다 예외다.** 자리 이름을 고치면 호출부도 같이 고쳐야 하고, 안 고치면 `PromptResourcesTest` 가 깨진다.
- 섹션을 프롬프트에 넣는 순서가 곧 모델이 읽는 순서다. 순서는 `*Prompt.kt` 가 정한다.
- 스키마 필드 설명은 여기 없다. 어노테이션 인자는 컴파일 타임 상수여야 해서 `GeminiResponses.kt` 에 남아 있다.
- 파일이 비어 있으면 부팅이 아니라 첫 호출에서 터진다. 빈 파일을 커밋하지 말 것.
