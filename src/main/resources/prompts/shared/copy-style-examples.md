## Korean copy: banned words and worked examples

### Banned

These apply to every Korean text field: `theme`, `recap.badge`, `recap.text`, `comments.speechBubbles`, `comments.keywordChips`. If a draft line contains one, rewrite the whole line — do not swap the word for a synonym.

- **Colorless adjectives** — 멋진, 멋짐, 즐거운, 행복한, 아름다운, 소중한, 특별한, 완벽한, 다채로운, 알찬, 뜻깊은, 값진
- **Filler nouns** — 순간, 시간, 하루, 추억, 기록, 일상, 모음, 컬렉션, 라이프, 스토리, 힐링, 감성, 필수템, 인생샷
- **Any "colorless adjective + filler noun" pairing at all.** That shape is the exact failure we are eliminating.
- **Slogan endings** — ~의 정석, ~ 그 자체, ~ 맛집 (unless it is literally a restaurant)
- **Category-label chips** — 여행, 음식, 카페, 친구, 가족, 데이트, 야경. Narrow them instead: "음식" becomes "탕수육 부먹".

### Worked examples

Five themes, each written badly and then correctly. The last two matter most: **most camera rolls are mundane, and that is exactly where the copy collapses into generic praise.** A theme with no event in it still has to name something only these photos contain.

| | BAD | GOOD |
|---|---|---|
| **badge** | 멋진 밤 🌃 | 새벽 라면각 🍜 |
| **text** | 즐거운 시간을 보냈어요. | 결국 국물까지 다 마셨다. |
| **bubbles** | 행복한 순간 · 좋은 추억 | 국물까지 완샷 · 내일 얼굴 붓는다 · 젓가락이 안 멈춤 |
| **chips** | 야경 · 추억 · 일상 | 새벽라면 · 국물파 · 후회는 내일 |

Why the BAD column fails: nothing in it names anything in the photos. Paste it under any other theme and it still fits.

| | BAD | GOOD |
|---|---|---|
| **badge** | 아름다운 바다 🌊 | 발만 담글 결심 🌊 |
| **text** | 특별한 하루였어요. | 결국 무릎까지 젖었다. |
| **bubbles** | 행복한 시간 · 최고의 순간 | 파도가 이겼다 · 신발 어디 갔어 · 소금기 대참사 |
| **chips** | 바다 · 여행 · 힐링 | 무릎까지 · 파도승 · 젖은양말 |

| | BAD | GOOD |
|---|---|---|
| **badge** | 귀여운 반려견 🐶 | 산책 조르는 중 🐶 |
| **text** | 소중한 추억을 남겼어요. | 현관 소리에 바로 튀어나왔다. |
| **bubbles** | 행복한 산책 · 예쁜 우리 강아지 | 목줄부터 물어옴 · 눈빛 협박 시작 · 다섯 걸음 만에 앉음 |
| **chips** | 강아지 · 산책 · 일상 | 산책조름 · 눈빛공격 · 잔디 킁킁 |

| | BAD | GOOD |
|---|---|---|
| **badge** | 소중한 단체사진 📸 | 같은 포즈 40장 📸 |
| **text** | 특별한 순간을 남겼어요. | 한 명이 눈 감아서 계속 다시 찍었다. |
| **bubbles** | 행복한 우리 팀 · 최고의 순간 | 이번엔 다 떴지 · 한 번만 더 · 뒤에 두 명 안 보여 |
| **chips** | 단체사진 · 추억 · 친구 | 배너 앞 · 같은 포즈 · 재촬영 · 맨 뒤 까치발 |

| | BAD | GOOD |
|---|---|---|
| **badge** | 즐거운 하루 🚇 | 환승 계단 정복 🚇 |
| **text** | 행복한 일상을 보냈어요. | 문 닫히기 3초 전에 탔다. |
| **bubbles** | 좋은 하루 · 행복한 순간 | 뛰어야 산다 · 카드 찍고 바로 · 자리는 없다 |
| **chips** | 지하철 · 일상 · 출근 | 환승 계단 · 3초 전 · 서서 감 · 다음 열차 |

There is nothing photogenic in those last two themes, and the GOOD column still works: it names the banner, the retakes, the closing door, the stairs. **A boring theme is not permission to write a boring line** — it is where you look harder at `observedDetails`.

Every GOOD line names something that had to be physically in the photo, and hands down a verdict instead of describing a mood. Do that.
